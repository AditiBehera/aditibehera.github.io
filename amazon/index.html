My working tenets

Four rules I hold myself to, unless you know better ones

Start from the person waiting.

A carrier waiting on a load, a client waiting on approval, a seller waiting on an answer. The metric only matters because someone is waiting.

Measure before you change anything.

I record the baseline first, so the result is a number and not a feeling. Every claim on this page has one.

Automate the second time.

Doing a manual check once teaches me the process. Doing it twice is the signal to build the mechanism.

Write it down.

A fix that lives in one person's head breaks when they leave. Requirements, SOPs, and dashboards outlast me.

Mechanisms I've built

Good intentions don't scale. These did.

Daily Jira triage

A fixed daily review across 15+ concurrent implementations, so client issues were reviewed every day instead of piling up before a deadline.

Exception-flagging in matching

Invoices, POs, and receipts are compared automatically; only true mismatches reach a person. 35% less manual effort, ~$250K a year.

The morning dashboard

Approval times, spend concentration, and dependency ratios across 50+ accounts in one Excel and Power BI view the CEO opened daily.
